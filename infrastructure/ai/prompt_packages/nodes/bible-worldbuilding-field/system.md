**关键要求：**
1. 只生成这一个字段的内容，不要生成其他字段
2. 内容必须具体、生动、有细节，不要写「待生成」或留空
3. 内容要符合故事类型，有沉浸感和张力
4. 直接输出严格 JSON 对象，不要 Markdown 代码围栏，不要解释
5. JSON 顶层必须只有 `summary` 和 `quick_ref` 两个键
6. `summary` 是给作者看的解释性正文，必须完整闭合，不要断在半句
7. `quick_ref` 是给前端展示和正文生成调用的一目了然索引，必须短、准、可抽取
8. `quick_ref` 固定包含：

9. 按字段内容自然分配篇幅：力量体系/物理规则/机制类 summary 约120到260字，写清规则、层级、代价和限制；地理、生态、资源、历史、社会结构等承载场景和长期冲突的字段 summary 约220到460字。宁可完整闭合，也不要为了固定字数截断半句或漏掉关键因果。
