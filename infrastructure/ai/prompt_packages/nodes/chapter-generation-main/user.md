━━ 叙事语调提醒 ━━

系统提示中给出了【风格约束】——那是本章的叙述腔调。写的时候让每个句子的节奏、用词、氛围都贴合那个腔调。如果风格要求「冷峻克制」，句子就硬而短；如果要求「市井烟火」，就用生活化的对白和细节。不要让风格约束成为摆设。

━━ 写的时候记住 ━━

• 每个换段（空行分段）里至少要有：具体动作、有信息的对话、发现/决定、或可见位移之一；不要连续两段纯写景凑字。
• 别平均使力。冲突爆发的地方多写两百字也值得，过渡的地方一笔带过就行。
• 场景里的人不能是纸片人。哪怕配角，也要有一个小动作或者眼神，让他活过来。
• 结尾要有落点。先让本章核心事件完成一个阶段性结果，再留一根刺：一个新问题、一个代价、一个更大的威胁。不要用半截对白、半截动作或刚出现的新事件来冒充钩子。
• 默认第三人称限制视角。除非文风公约或大纲明确要求第一人称，正文不要用“我/我们/我的”叙述；应用角色名或“他/她”的贴身感知来写，而不是让叙述者自称“我”。
• 不管本章是什么题材，都要写到本章结果：信息被确认、目标暂时达成或失败、代价显现、角色做出选择、关系发生变化，或危机被解决/升级。不要停在新物件、新声音、新人物、新提示、新异象刚出现的瞬间。
• 每个场景都要'双线并行'——表面事件 + 底层暗流。读者看完后应该觉得'这件事不简单'。
• 如果上一章结束时角色处于某种状态（紧张/受伤/震惊），本章开头必须先接住这个状态再展开新情节。
• 情绪通过动作和感官细节传递——不写'他感到愤怒'，写'他端起杯子又放下了'。
• ⚠️ 段落聚合铁律：属于同一视觉焦点、同一动作链或同一心理转折的句子必须合并在同一段落里。只有冲突引爆/重大揭露/情绪暴击的瞬间，才用一句独段制造暴击感，但全章独段比例不得超过15%。
