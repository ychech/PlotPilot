{outline}

━━ 叙事语调提醒 ━━

系统提示中给出了【风格约束】——那是本章的叙述腔调。写的时候让每个句子的节奏、用词、氛围都贴合那个腔调。如果风格要求「冷峻克制」，句子就硬而短；如果要求「市井烟火」，就用生活化的对白和细节。不要让风格约束成为摆设。

━━ 写的时候记住 ━━

• 先在心里给本章打标签：题材标签、世界观规则、主角阶段、叙事功能、阶段结果。不要把标签写进正文，但正文必须体现它们。
• 先想清楚本章变化量：这一章结束后，主角处境/敌我格局/关键关系/核心信息中至少两项发生明确改变。一章只讲一件事的一个片段是严重问题——比如"某人来了然后结束""消息传到了然后结束""地方到了然后结束"都不够，必须把"来之后的冲突""消息引发的抉择""到之后的麻烦"写进同一章。如果大纲给的事件量不够填满一章，往前推到冲突爆发，或把前后事件合并。
• 本章必须有强结构：承接上一章状态 → 激励事件 → 主角应对 → 阻力升级 → 高潮转折 → 阶段结果 → 结果之后的钩子。哪怕是过渡章，也要有选择、信息或关系变化。
• 如果本章有打斗，按当前文风、主角实力阶段和已知力量规则来写。打斗要产生结果或代价，不能只堆招式、喊境界、突然开挂。
• 节拍不是摆设。每个节拍都要让局势往前走一点：发现新信息、逼出选择、扩大阻力、付出代价、完成反击或落下结果。不要把同一个情绪和同一句威胁换说法重复写。
• 每个换段（空行分段）里至少要有：具体动作、有信息的对话、发现/决定、或可见位移之一；不要连续两段纯写景凑字。
• 别平均使力。冲突爆发的地方多写两百字也值得，过渡的地方一笔带过就行。
• 场景里的人不能是纸片人。哪怕配角，也要有一个小动作或者眼神，让他活过来。
• 结尾要有落点。先让本章核心事件完成一个阶段性结果，再留一根刺：一个新问题、一个代价、一个更大的威胁。不要用半截对白、半截动作或刚出现的新事件来冒充钩子。
• 默认第三人称限制视角。除非文风公约或大纲明确要求第一人称，正文不要用“我/我们/我的”叙述；应用角色名或“他/她”的贴身感知来写，而不是让叙述者自称“我”。
• 不管本章是什么题材，都要写到本章结果：信息被确认、目标暂时达成或失败、代价显现、角色做出选择、关系发生变化，或危机被解决/升级。不要停在新物件、新声音、新人物、新提示、新异象刚出现的瞬间。
• 结尾画面要能成为下一章的承接锚点：留下已发生结果带来的问题、伤口、代价、线索或更大威胁，而不是把正文停在刚开头的事件上。
• 每个场景都要'双线并行'——表面事件 + 底层暗流。读者看完后应该觉得'这件事不简单'。
• 如果上一章结束时角色处于某种状态（紧张/受伤/震惊），本章开头必须先接住这个状态再展开新情节。
• 情绪通过动作和感官细节传递——不写'他感到愤怒'，写'他端起杯子又放下了'。
• 段落聚合：同一视觉焦点或动作链内的句子自然合并，不要每句话都另起一段。冲突引爆/重大揭露/情绪暴击瞬间可以用一句独段制造冲击力，但全章不要过度碎段。段落结构要有变化——三句一段、五句一段、一行独段交替出现，不要所有段落都是同一种长度。
	• 写完回头自检：有没有连续三段结构雷同（比如连续三段都是"动作句+感官句+对话句"）？有没有为了凑信息密度每隔一段硬塞一句"发现"？有没有把"承接→激励→应对→升级→转折→结果→钩子"写成流水线模板，每步一段、段落一样长？如果发现了，把僵硬的地方打散重写，让叙事呼吸自然一些。
