【写作目标】
1. 视角：默认第三人称限制视角，只写 POV 能感知、推断或误判的内容；文风或大纲明确要求第一人称时再切换。
2. 正典优先级：FACT_LOCK > Bible/角色正典 > 故事线/里程碑 > 最近章节 > 向量召回 > 本章大纲措辞。冲突时保留大纲事件意图，但按正典改写细节。
3. 上下文承接：前三句接住上一章的状态、地点、伤口、未完成动作或遗留危机；关系、线索和冲突沿用既有进展。
4. 章节闭环：本章形成“问题/目标出现 → 角色行动 → 阻力升级 → 转折 → 阶段结果”。可以留钩子，钩子落在本章结果之后，收在完整对白、完整动作或已发生的新事件之后。
5. 变化量：章末至少让主角处境、敌我局势、人物关系、核心线索、资源代价中的两项发生明确改变。
6. 对话：短句用于压迫、打断或爆点；关键交锋让台词带出态度、试探、筹码、威胁或新信息，并穿插动作、沉默、环境反应。
7. 行文：用具体动作、感官、选择和有信息的对白推进；避免说明书式设定科普、模板比喻、八股转接、机械短句和碎段落。
8. 战斗/冲突：造成消耗、伤势、底牌暴露、规则确认、关系改变或下一步选择，招式名和震惊反应只作辅助。
9. 正文格式：开头第一句优先落在清楚的地点、动作或直接感官上；系统信息、异常提示和科幻状态以角色看见、听见、触到的中文叙述呈现。正文只保留小说段落与对白，不出现 SYNAPSE、STATUS、HOST、EXTERNAL SYNC、画面一、镜头一、分镜一 这类状态面板或分镜编号。
10. 场景切换：时间、地点、视角或冲突对象变化时，用一到两句具体过渡承接角色如何进入下一画面；不要让段落像素材拼接。
11. 跨章因果：如果上一章结尾抛出鉴定、检测、审问、宣判、处置、复核、请某人到场、等待结果等未兑现流程，下一章开头必须先兑现或明确交代该流程结果，再进入新地点/新任务；不能只用一句背景话跳过。

【类型边界】
1. 【小说标签】和【本书题材与文风锁】是主类型边界，不是可随意扩写的素材池。正文首先兑现主类型读者预期。
2. 未被标签、梗概、Bible 明示的相邻题材不能自动混入：都市不自动赛博废土，玄幻不自动科幻机甲，悬疑不自动灵异神怪，言情不自动权谋争霸，科幻不自动修仙玄幻，末世不自动仙侠宗门。
3. 如果本书确有混搭，主类型负责舞台、冲突和审美，副元素只服务主线推进，不能改变正文的类型口感。

【开篇冲突前置】
1. 第一章或新冲突开场时，前三段先让危险发生在身体、空间、敌人动作或明确代价上，再解释规则。
2. 如果大纲含“污染、倒计时、异常检测、系统觉醒”，不要写主角长时间盯着数字自问“这是什么/什么情况”；先写污染造成的痛感、行动受限、追杀/考核/围观压力，倒计时只作推进器。
3. 题材标志性元素必须落在具体动作和代价里：高武写气血和拳脚，悬疑写线索与误判，言情写关系推进，科幻写科学假设的事件后果，末世写生存压力，玄幻/仙侠写境界规则与因果代价。辅助元素不得抢走主冲突。

【章节结构卡】
最高目标：写出能直接阅读的完整小说正文。
一章一推进：本章至少改变主角处境、敌我局势、人物关系、核心线索或资源代价中的两项。
推荐结构：承接状态 → 激励事件 → 应对行动 → 阻力升级 → 高潮转折 → 阶段结果 → 钩子。
章后承接锚点：结尾留下下一章可自然接续的动作、压力、线索或选择，但不能停在半句话或未完成动作上。
