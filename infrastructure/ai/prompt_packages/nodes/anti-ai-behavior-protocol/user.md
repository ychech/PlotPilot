【核心协议：P1-P5】

P1. 信息密度法则
  每个段落推进以下至少一项：剧情事实、角色关系、悬念线索、信息差变化。
  以换段为准：每段落地一类可复述事件，例如具体动作带后果、有信息对白、发现或决定、可见位移；连续写景段也配合人物动作、对白或取舍。
  写完一段后自查：这段删掉会影响读者理解吗？不会就删掉。

P2. 感官优先法则
  当你需要表达情绪或氛围时，执行顺序：
  感官细节（温度/光线/声音/触感/气味）→ 动作变化 → 对话内容
  通过前两步让情绪自己显形，减少直接情绪标签。

P3. 角色差异化法则
  不同角色面对同一事件时呈现不同反应方式。
  反应方式 = 角色背景 × 当前身体状态 × 与事件的利益关系。
  每个角色有专属紧张习惯：{nervous_habits}

P4. 节奏与段落法则
  节奏快 → 句子短促，动词前移，主语可省；短句不等于短段，同一动作链内的连续短句合并在同一段落。
  节奏慢 → 长短交替，感官细节穿插，铺陈段落2-5句有机聚合。
  连续句子长度保持变化，避免 3 句以上完全同形。
  全章独段（1句成段）比例控制在15%以内，仅限冲突引爆/重大揭露/情绪暴击的瞬间使用。

P5. 衔接法则
  节拍间无断点。情绪有惯性。
  上一段在愤怒，下一段先承接身体、语气或行动余波，再进入新状态。
  时间过渡需要具体动作或空间变化支撑，避免单靠“后来/之后/转眼间”跳走。

【替换策略：检测到B类模式时执行】

R1. 情绪 → 找到角色此刻最可能做的小动作（手停住/话顿了一下/杯子端到嘴边又放下）
R2. 微表情 → 写完整姿态变化，或不写，让对白本身传递
R3. 比喻 → 写此刻的体温、光线角度、衣料触感
R4. 声线 → 用对白的标点和断句表现语气
R5. 纠正式对照 → 拆成平叙两句，或直接写动作与结果
R6. 破折号 → 句号断开，让节奏自己制造停顿
R7. 动物比喻 → 删掉，用人的动作描写
R8. 生理性 → 直接写生理反应（眼睛酸了/鼻子红了/声音发闷）
